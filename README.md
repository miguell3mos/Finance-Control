# FinanceControl

Aplicativo desktop para gestão financeira pessoal.

## Objetivo

Criar um software para controlar receitas, despesas, contas, metas
e visualizar a situação financeira através de gráficos e relatórios.

## Tecnologias

- Python
- PySide6
- SQLite
- Matplotlib
- Git
- GitHub
